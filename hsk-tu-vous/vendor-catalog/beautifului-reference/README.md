# Beautiful UI reference (public MIT demo, not ready-to-use React source)

Canonical website: https://www.beautifului.dev/
License: https://www.beautifului.dev/license (MIT, Shane Levine, 2026).
These two HTML files are a dated snapshot of the public website and license page.
**They are not a working React component package** and must not be imported into
the Remotion renderer. Their inline/linked scripts, if any, are demo-site assets.
Before adapting any component, inspect provenance, dependencies, video safe zones
and the current license; implement only the scenes selected for actual video use.
