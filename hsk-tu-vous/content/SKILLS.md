В `.agents/skills/` установлены 36 пакетов из предоставленной владельцем локальной папки `/Users/kaijimima1234/.agents/skills/`. Скопированы `SKILL.md` и вспомогательные файлы; существующий `heroui-react` сохранён. Пакеты доступны локально и не требуют сетевого скачивания для чтения. Они не являются зависимостями рендера.

## Перед применением

1. Прочитайте `AGENTS.md`, `AI_RULES.md` и `PROJECT_MEMORY.md`, затем проверьте дату в `content/calendar.json`.
2. Выберите skill по реальной задаче. Прочитайте его `SKILL.md` и только нужные для задачи ссылки. Установка пакета не означает, что все его workflows нужно запускать для каждого ролика.
3. Следуйте актуальному запросу владельца и установленным правилам HSK. Сначала согласуйте общую инструкцию skill с текущим календарём, брендом, голосом, форматом и runtime.
4. Проверяйте готовые кадры, звук, титры и пакет по `content/EDITING_SPEC.md` и `content/WORKFLOW.md`.

## Границы общих workflows

- Упоминания ElevenLabs, Whisper, Gemini или другого TTS в общих skills не меняют утверждённый процесс. Для серии используется только `text-to-speech.online`, Dmitry – RU и соответствующие пословные captions.
- Шаблоны чужого бренда, длительности и формата применяются только в пределах актуального запроса. Текущая серия сохраняет русский язык, 1080×1920, 25–35 секунд, открытый центральный stage и фиксированный CTA.
- Общие команды публикации или загрузки не разрешают публикацию HSK-ролика. Пакет остаётся в `review/<episode-id>/` для просмотра владельцем и ручного размещения.
- Установка skills не меняет календарь. При отсутствии сегодняшней даты действуйте по `content/WORKFLOW.md`: назовите следующую запланированную дату и тему, сообщите, что рендер не выполнялся. Новая дата требует явного запроса владельца на изменение плана.
- Не запускайте scaffold, обновление зависимостей, подключение API или миграцию только потому, что это стандартный шаг общего skill. Для текущей серии сохраняйте работающую архитектуру.

Копии пакетов зафиксированы в проекте; обновляйте их отдельно от обычного производства ролика, сохраняя локальные изменения и существующие skills.
